# Pruebas de práctica — Evaluación Parcial 1

Paquete de autoevaluación para repasar los 6 temas antes de la prueba. Está pensado para hacerlo **en orden**, sin mirar las respuestas hasta terminar cada parte.

## Cómo usarlo

1. **`01-teoria/`** — 24 preguntas de teoría (opción múltiple, verdadero/falso, "qué imprime este código"). Respóndelas en un papel o documento aparte. Recién ahí abre `respuestas.md` a corregir.
2. **`02-debugging/`** — 6 fragmentos de código con errores reales (de los típicos que vimos). Identifica el error y cómo lo arreglarías, ANTES de mirar `respuestas.md`.
3. **`03-ejercicios-codigo/`** — 3 ejercicios de código nuevos (con otro tema/dominio, no son copia de las guías) para escribir tú mismo en IntelliJ. Las soluciones verificadas están en `soluciones/`, pero intenta resolverlo solo primero — ábrelas solo para comparar o si quedas muy trabado.
4. **`04-simulacro-examen.md`** — simulacro cronometrado (90 min) que mezcla teoría rápida + debugging + un problema de código, simulando el formato real de la evaluación.

## Recomendación de uso

- Hazlo **sin IA y sin apuntes** la primera vez (como sería la prueba real), cronometrado.
- Corrige con las respuestas.
- Lo que falles, anótalo en la sección "Dudas / para repasar" del README principal del proyecto — así queda registrado y lo repasamos juntos.
- Repite `04-simulacro-examen.md` un par de días después para confirmar que quedó afianzado.
